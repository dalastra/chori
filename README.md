# CHORI — Landing Page

Landing page estática para o CHORI — Empanadas Argentinas & Choripán.

## Tecnologias
- HTML5
- CSS3
- JavaScript Vanilla

## Estrutura
- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/images/`
- `assets/icons/`

## Observações
As imagens demonstrativas estão usando URLs do Unsplash para facilitar a visualização imediata. Para publicação definitiva, substitua-as pelas fotos reais do CHORI em `assets/images/`.

O link de Instagram deve ser substituído pelo Instagram oficial do restaurante caso seja diferente do endereço configurado no HTML.

O botão de WhatsApp usa um link genérico com mensagem pronta. Para produção, troque pelo número oficial no formato internacional:
`https://wa.me/55DDNUMERO?text=...`

O mapa foi construído como representação visual estilizada. O botão "Como chegar" abre o Google Maps com o endereço informado no briefing.
